# Portfolio

Single-page portfolio: plain HTML, CSS and JS. No build step, no WordPress or template files needed.

## Files
- `index.html`: the whole site
- `web.webp` / `web.png`: hero photo (webp is used when supported)
- `pn.jpg`: testimonial photo

## To finish
1. Add your CV as `Alok_Singh_CV.pdf` next to `index.html` (the Download CV button points to it).
2. Edit the `PROJECTS` and `TESTIMONIALS` arrays near the bottom of `index.html` to change your works and feedback.
3. Replace the LinkedIn link (`https://linkedin.com/`) with your profile URL.
